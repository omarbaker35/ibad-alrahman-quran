# مدرسة عباد الرحمن لتحفيظ القرآن الكريم وتجويده

مشروع موقع ثابت **HTML + CSS + JavaScript** بدون Python، مناسب للجوال، بواجهة عربية RTL وتصميم إسلامي.

## الملفات

```text
index.html
style.css
app.js
manifest.webmanifest
sw.js
media/
  audio/
  pdf/
```

## التشغيل على جهازك

### الطريقة الأسهل

افتح ملف `index.html` مباشرة بالمتصفح.

### طريقة أفضل أثناء التطوير

استخدم إضافة **Live Server** في VS Code:

1. افتح مجلد المشروع في VS Code.
2. ثبّت إضافة Live Server.
3. اضغط يمين على `index.html`.
4. اختر `Open with Live Server`.

## كلمة مرور لوحة الإدارة

كلمة المرور الافتراضية:

```text
1234
```

يمكن تغييرها من صفحة **الإدارة > إعدادات ونسخ احتياطي**.

## إضافة التسجيلات والمواد

يوجد خياران:

### 1. إضافة روابط عامة مناسبة للنشر

ضع ملفات الصوت داخل:

```text
media/audio/
```

وملفات PDF داخل:

```text
media/pdf/
```

ثم أضف المسار من لوحة الإدارة، مثل:

```text
media/audio/juz-30/al-naba.mp3
media/pdf/tajweed-summary.pdf
```

هذه الطريقة مناسبة ليشاهد الجميع الملفات بعد نشر الموقع.

### 2. رفع ملفات من لوحة الإدارة

يمكن رفع صوت أو PDF من لوحة الإدارة، لكن انتبه:

- الملفات تحفظ داخل نفس المتصفح فقط باستخدام IndexedDB.
- لن تظهر هذه الملفات لباقي الزوار بعد النشر.
- هذا طبيعي لأن المشروع بدون Backend أو قاعدة بيانات.

## النشر أونلاين

هذا المشروع ليس Streamlit ولا يحتاج Python. أنسب نشر له:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

### النشر على GitHub Pages باختصار

1. أنشئ Repository جديد على GitHub.
2. ارفع ملفات المشروع كلها.
3. من Settings اختر Pages.
4. اختر Branch: `main` و Folder: `/root`.
5. احفظ، وسيظهر رابط الموقع.

## ملاحظات مهمة للخبير

- الموقع يعمل كـ SPA باستخدام `location.hash`، لذلك لا يحتاج إعدادات Redirect خاصة.
- يوجد Service Worker بسيط للتخزين المؤقت عند النشر على HTTPS.
- التصميم RTL ومتجاوب مع الشاشات الصغيرة.
- كلمة مرور الإدارة في موقع Static ليست حماية حقيقية؛ هي فقط لمنع الاستخدام العشوائي. للحماية الحقيقية تحتاج Backend.
- لإدارة محتوى عامة من عدة أجهزة، تحتاج قاعدة بيانات أو CMS مثل Firebase / Supabase / Directus.
